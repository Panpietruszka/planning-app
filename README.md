**Architect Pro** to nowoczesna aplikacja webowa służąca do wizualizacji i zarządzania strukturami danych w czasie rzeczywistym. Projekt stawia na wysoką estetykę interfejsu (Visual Hierarchy) oraz płynność działania dzięki integracji z ekosystemem Firebase.
**Architect Pro** is a modern web application designed for real-time visualization and management of data structures. The project prioritizes high-end interface aesthetics (**Visual Hierarchy**) and seamless performance via integration with the **Firebase** ecosystem.

---

## ✨ Kluczowe Funkcje
## ✨ Key Features

- 🔐 **Zaawansowana Autoryzacja**: System logowania i rejestracji (Email/Hasło) oraz szybkie logowanie przez **Google Auth**.
- 📂 **Zarządzanie Projektami**: Tworzenie, edycja i usuwanie kolekcji oraz projektów w chmurze.
- 🎨 **Personalizacja UI (Live)**: 
  - Dynamiczna zmiana głównego koloru akcentu (Color Picker).
  - Regulacja zaokrąglenia rogów (Border Radius) i przezroczystości interfejsu.
  - Efekty Glassmorphism (regulacja rozmycia tła).
- ☁️ **Cloud Sync**: Pełna synchronizacja z **Firestore** oraz **Firebase Storage** dla plików graficznych.
- 🌓 **Modern Dark Theme**: Interfejs zoptymalizowany pod kątem pracy w nocy, oparty na fontach *Plus Jakarta Sans*.
* 🔐 **Advanced Authentication**: Secure sign-up/login system (Email/Password) and quick access via **Google Auth**.
* 📂 **Project Management**: Create, edit, and delete cloud-based collections and projects.
* 🎨 **Live UI Personalization**: 
    * Dynamic primary accent color adjustment (**Color Picker**).
    * Adjustable **Border Radius** and interface transparency.
    * **Glassmorphism** effects (adjustable background blur).
* ☁️ **Cloud Sync**: Full synchronization with **Firestore** and **Firebase Storage** for media files.
* 🌓 **Modern Dark Theme**: Interface optimized for night-time productivity, featuring the *Plus Jakarta Sans* typeface.

## 🛠️ Technologie
## 🛠️ Tech Stack

Projekt wykorzystuje najnowsze standardy webowe:
The project utilizes the latest web standards:

* **Frontend**: HTML5, ES6+ JavaScript (Moduły).
* **Stylizacja**: [Tailwind CSS](https://tailwindcss.com/) + Custom CSS Properties dla dynamicznych motywów.
* **Frontend**: HTML5, ES6+ JavaScript (Modules).
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) & **Custom CSS Properties** for dynamic theming.
* **Backend**: [Firebase 11.1.0](https://firebase.google.com/) (Auth, Firestore, Storage).
* **Ikony**: Custom SVG Icons.
* **Icons**: Custom SVG Icons.
