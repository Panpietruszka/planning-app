**Architect Pro** is a modern web application designed for real-time visualization and management of data structures. The project prioritizes high-end interface aesthetics (**Visual Hierarchy**) and seamless performance via integration with the **Firebase** ecosystem.

---

## ✨ Key Features

* 🔐 **Advanced Authentication**: Secure sign-up/login system (Email/Password) and quick access via **Google Auth**.
* 📂 **Project Management**: Create, edit, and delete cloud-based collections and projects.
* 🎨 **Live UI Personalization**:     
    * Dynamic primary accent color adjustment (**Color Picker**).    
    * Adjustable **Border Radius** and interface transparency.    
    * **Glassmorphism** effects (adjustable background blur).
* ☁️ **Cloud Sync**: Full synchronization with **Firestore** and **Firebase Storage** for media files.
* 🌓 **Modern Dark Theme**: Interface optimized for night-time productivity, featuring the *Plus Jakarta Sans* typeface.

## 🛠️ Tech Stack

The project utilizes the latest web standards:

* **Frontend**: HTML5, ES6+ JavaScript (Modules).
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) & **Custom CSS Properties** for dynamic theming.
* **Backend**: [Firebase 11.1.0](https://firebase.google.com/) (Auth, Firestore, Storage).
* **Icons**: Custom SVG Icons.

## 🚀 Quick Start

### Prerequisites
* A modern web browser (Chrome, Edge, Firefox, etc.).
